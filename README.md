# bank-eng-prep
A repo outlining the preparation tasks prior to commencing a software engineering role at a bank. 

Compromised of six sprints, each with tickets aligning to the overarching criteria related to completing the sprint, and becoming more prepared for the upcoming role. 

The goals and tasks within each of the sprints are as follows: 

Sprint 1 (BEP-1 to BEP-5) - Toolchain ready, the daily java habit running, and your first tested Java program merged. 

Sprint 2 (BEP-6 - BEP-10) - Work like a team engineer (Gradle, PRs, Git recovery) and scaffold accounts-api on Spring Boot 

Sprint 3 (BEP-11 - BEP-16) - A production-shaped REST service that runs with one command and has 20+ tests 

Sprint 4 (BEP-17 - BEP-20) - Two services talking through Kafta. 

Sprint 5 (BEP-21 - BEP-25) - accounts-api on Kubernetes with a green CI pipeline and a security scan. 

Sprint 6 (BEP-26 - BEP-31) - Banking vocabulary, basic security, and a polished repo to show on day one.
